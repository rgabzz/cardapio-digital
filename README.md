# Cardápio Digital

Um sistema de cardápio digital desenvolvido para facilitar a visualização dos produtos de um estabelecimento de forma simples, prática e acessível.

## 👨‍💻 Criadores

- **Francisco Wandson Gomes Martins**
- **Riedson Gabriel Pereira Brasil Monteiro**

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📌 Sobre o projeto

O Cardápio Digital foi desenvolvido com o objetivo de oferecer uma alternativa moderna aos cardápios tradicionais, permitindo que os clientes consultem os produtos de maneira digital e organizada.
